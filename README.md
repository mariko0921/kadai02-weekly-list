## ⑤工夫した点・こだわった点
- 単なるTODOリストではなく、継続的な習慣化を目的としたアプリにしたこと
- 習慣化したい項目をLocalStorageに保存し、毎日登録し直さなくても継続して表示される仕様にした
- 日々の達成率を数値やグラフで可視化し、達成感を得られるようにした
- 項目の追加・編集・削除ができ、自分の生活に合わせてカスタマイズできるようにした


## ⑥難しかった点・次回トライしたいこと（又は機能）
- 習慣化したい項目と、その日だけのTODOを分けて表示する機能
- 項目ごとに連続達成日数をカウントする機能
- 21日間連続で達成するとご褒美演出が表示されるなど、楽しみながら習慣化できる仕組み（21日連続でやると習慣化しやすくなるというお話を聞いたことがあるため。）

## ⑦フリー項目（感想、シェアしたいこと等なんでも）
- 「21日間継続することで習慣化につながる」という考え方をヒントに、日々の行動を習慣化するためのアプリをつくりたかった。
実際につくってみると、単にタスクを管理するだけでなく、継続したくなる仕組みやデータの保存方法、表示の切り替えなど、細かな仕様を考えて実装するのが難しい。
タスクをこなすためのアプリではなく、楽しみながら習慣化できるアプリに進化させていきたかったが、、実装が間に合わなかった
